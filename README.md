# git_short_instruction
1) Установка git (не забыть проверить PATH)
2) Описать юзера
   git config --global user.name "имя"
   git config --global user.email "почта"
3) Создание репозитория 
4) Создание клона репозитория
    git clone <ссылка на репозиторий>
5) Создание ветки и переход в неё
    git checkout -b <имя ветки>
6) Работа с веткой
7) Выбор файлов для фиксации (-A это всей файлы)
    git add -A
8) Фиксация результатов
    git commit -m "описание результатов"
9) Перенос commit из локального репозитория в удаленный
    git push
    

* git fetch - для обновления локального репозитория
* git push --set-upstream origin git_start (если в удаленном репозитории нет ветки, то push нужно выполнить так)
