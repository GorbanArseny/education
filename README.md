# spark_streaming
1) server - локальный сервер, который принимает данные от одного клиента и передает другому
2) client_sender - клиент, который передает данные на сервер
3) client_reader - читает данные от сервера и выводит их
4) client_streamer - spark streaming клиент, который берет данные от сервера, производит их пооконную агрегацию и выводит
5) socket_threading_streaming - всё ранее описанное, вместе взятое (не для запуска)
